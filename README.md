# 지리산이음 네트워크 지형도

사회적협동조합 **지리산이음**이 2015~2026년 사이 누구와 어떻게 관계를 맺어왔는지를,
제출 원자료만 근거로 정리한 분석 문서입니다.

**브라이언임팩트 임팩트그라운드** 사업의 지원을 받는 지리산이음이 제출한 자료를
바탕으로 작성했으며, **지리산이음**과 임팩트 측정을 맡고 있는
**한국사회가치평가**와 공유하기 위해 만들었습니다.

👉 **[문서 열기](https://josang-impact.github.io/jirisaneum-network/)**

## 무엇을 다루나

| 항목 | 내용 |
|---|---|

| 마을(산내) | 2023년 면 전수조사, 모두발표회 · 지리산쌀롱 · 대정길 잔치, 토닥의 전환 |

| 데이터 정합성 | 같은 해 수치가 문서마다 다른 지점 정리 |

## 핵심 발견

**지리산포럼 재참여율이 11년 내내 올랐습니다.** 11.2%(2016) → 43.2%(2026).
고유 참가자 1,100명 중 232명이 두 번 이상 참여했고, 최다 참여자는 9회입니다.
관계가 실제로 축적됐다는 것을 보여주는 가장 직접적인 근거이며,
이 수치는 아직 임팩트그라운드 보고서에 등장한 적이 없습니다.

동시에 신규 참가율은 100%에서 56.8%로 내려왔고, 참가자 규모는 2019년(172명)과
2024년(173명)이 거의 같습니다. **커지는 대신 깊어지는 쪽으로 간 궤적**입니다.

## 데이터 출처

`임팩트 보고서_제출자료` 폴더의 **문서 192건을 전수 판독**했습니다.

- 사업영역별 정리자료 7종 (마을 · 지리산권 · 지리산포럼 · 변화를만드는사람들 · 엣지 · 전국활동 · 해외연수)
- 지리산포럼 임팩트자료 — 역대 참가자 명단, 재참여 분석, 협력기관 변화, 참여현황 분석
- 정기총회 자료집 2020~2026 (통합 결산 · 감사보고서)
- 임팩트그라운드 사업계획서 · 중간보고 · 결과보고 2022~2026
- 홈페이지 · 콘텐츠 통계 2021~2026, 프로그램별 참여자 명단
- 2025 임팩트리포트 초안 (한국사회가치평가 측정)

## 집계 기준

분석에는 **세 가지 값만** 썼습니다 — 참가자 명단을 집계한 수, 함께한 기관 수, 결산 금액.
원자료에 근거가 남아 있고 세는 기준이 분명한 값입니다.
서술형 요약에만 등장하는 "약 ○○여 명" 같은 값은 쓰지 않았습니다.

## 읽을 때 주의할 점

**같은 해 포럼 참가자 수가 자료마다 최대 네 가지입니다.**
예를 들어 2025년은 명단 집계 146명, 정리자료 180명 이상, 결과보고서 191명입니다.
이 문서는 명단 집계값을 씁니다. 2020년 성과 시트의 638명은 온라인 조회수가
섞인 값이고, 명단 기준 참가자는 153명입니다.

명단 225곳은 **2023년 이후에 치우쳐** 있습니다.
2019~2022년 보고서가 협력처 이름을 거의 적지 않았기 때문이며,
문서 안에도 경고로 표시해 두었습니다.
